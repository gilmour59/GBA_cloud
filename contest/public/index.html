Need a hint?

Use ROW_NUMBER() OVER (PARTITION BY record_id ORDER BY row_uid) to keep the first copy. SQLite may cast text such as n/a to zero, so check that the source text is numeric before casting.

Editable SQL

Group by place. Yield is total production divided by total harvested area.

Need a hint?

For each place, use SUM(production_mt) and SUM(harvested_area_ha). Divide those totals for an area-weighted yield. Avoid averaging row-level yields.
