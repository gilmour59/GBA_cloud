# HTML presentation — source of truth

Open or download [index.html](index.html). The original [Google Slides draft](https://docs.google.com/presentation/d/1ISXQBh2vxGKsdH-0Jnx-BNxJ1EEM17SBEM9agKYvnzA/edit) is archived for reference only and will no longer be maintained.

Current: **32 HTML slides**, each with full speaker script. Exactly **three scenario-based discussion questions**. Custom diagrams and a visual-first dark-tech theme. Arrow keys for navigation; **P** for dual-window presenter mode, with timer and independently scrollable notes. Projection should use Extend Display, not Mirror.

The two new teaching slides make the analysis process explicit: question → profile → prepare → aggregate → validate → interpret → communicate, and an example contrasting total crop production and yield/area. Example numbers are fictional and not research results.

The simulation preview describes the standalone browser activity: synthetic Rice demonstration, then Cacao practice with editable Silver and Gold SQL, stage checks, accuracy verification, and a dashboard comparison. It is Databricks-inspired; SQL runs in the browser rather than on Databricks.
