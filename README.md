# Big Data Analytics and Cloud-Based Data Engineering

WVSU Master in Information Technology reporting project.

## Deliverables
- Research-based presentation in **Google Slides**, with slide-by-slide presenter notes and APA-style citations.
- **Three** scenario-based classroom discussions (architecture selection, pipeline quality, and cloud deployment choices).
- Reproducible **Databricks Free Edition** teaching simulation using **synthetic** Western Visayas agricultural data: ingestion → Bronze → Silver → Gold → analytics, dashboard, and Delta version history.

## Project tracking
See [KANBAN.md](KANBAN.md) and the repository [Issues](https://github.com/gilmour59/GBA_cloud/issues). GitHub issues are the actionable tasks; the Markdown Kanban gives a quick overview.

## Sources
1. Armbrust et al. (2023), *Making Data Engineering Declarative*, CIDR 2023.
2. Harby & Zulkernine (2025), *Data Lakehouse: A Survey and Experimental Study*, Information Systems 127, 102460.
3. AbouZaid et al. (2025), *Building a Modern Data Platform Based on the Data Lakehouse Architecture and Cloud-Native Ecosystem*, Discover Applied Sciences 7, 166.
